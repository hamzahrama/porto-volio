## Format yang Disarankan
- **Format**: JPG atau PNG
- **Rasio**: 4:3 (landscape) atau 1:1 (square)
- **Ukuran**: Max 500KB per foto untuk loading cepat
- **Namakan file** sesuai daftar di atas (lowercase, pakai strip `-`)

## Cara Cepat
1. Copy foto ke folder ini
2. Rename sesuai nama file di atas
3. Refresh browser - foto otomatis muncul di album

**Note**: Jika foto tidak ditemukan, akan tampil placeholder dengan judul fotonya.
