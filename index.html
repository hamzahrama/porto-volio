Tentang Saya

Halo! Saya Paramatama Hamzah Boyle Fairuz, seorang Web Developer & pendiri Boyle Byte Dev House berbasis di Yogyakarta. Lulusan MA yang memiliki semangat tinggi untuk memberikan manfaat bagi lingkungan sekitar melalui teknologi.

Perjalanan saya bermula dari dasar-dasar web seperti HTML, CSS, JavaScript, PHP, dan phpMyAdmin. Seiring berjalannya waktu, saya terus belajar dan kini berfokus pada teknologi modern: NestJS, Next.js, TypeScript, Neon, Supabase, dan Git & GitHub.

Saya belajar melalui Pondok IT, BLK Kudus, serta secara mandiri lewat tutorial YouTube dan pendampingan AI. Saat ini, saya fokus mengembangkan aplikasi full-stack berperforma tinggi. Salah satu proyek yang sudah dideploy ke Vercel adalah Taskify Kanban, aplikasi papan tugas untuk efisiensi manajemen kerja. Saat ini saya juga sedang mengembangkan Minipost, aplikasi POS & manajemen stok untuk membantu pelaku usaha.
